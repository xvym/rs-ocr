# rs-ocr

面向日版《宝可梦 红宝石／蓝宝石》的 Windows 离线 OCR 翻译项目。

已构建后可双击 [start-desktop.cmd](start-desktop.cmd) 打开独立窗口，启动器自动寻找 Java 21；当前机器可直接复用已有工具链。

关闭窗口会直接停止任务并退出，不再重绘结果或生成诊断信息，避免诊断组件异常阻断关闭。启动器按程序哈希创建固定运行副本，后续重新构建不会覆盖已打开窗口使用的程序包。空闲、打开图片、实时采集及模拟诊断组件异常的退出检查通过，详见 [退出检查记录](reports/shutdown/idle.json)、[异常检查](reports/shutdown/diagnostic-error.json)和[实时检查](reports/shutdown/live.json)。

项目已建立 Java 21 离线日文 OCR 入口，并通过 S3 固定实机截图验收：现有 456 张原图、579 个目标在冻结同形字规则下全部正确，CER=0；严格字符一致 577 项。S4 独立窗口已实现，S5 已接入窗口实时捕获、游戏区域校准和结果失效管理；456 张受控回放及 23 个状态场景通过。实际 NDS／NGC 连续链路验收、中文和发行交付尚未完成。

实时模式已调整为文字连续稳定 150ms 后再识别，选择光标和等待箭头动画不反复触发文字识别；结果区对光标显示防抖，内容不变时跳过重绘。更新后关闭旧窗口，再双击启动器使用新版。验证记录见 [稳定触发与防闪烁](reports/s5-live/README.md#稳定触发版本的验证)。

实时窗口采集默认排除 Windows 系统标题栏和外框，只保留窗口内容区。软件自行绘制的标题栏、菜单、工具栏和 OBS 外层画布仍需通过“校准游戏区域”排除。校准坐标从内容区左上角开始；更新后请重启程序并重新框选需要手动校准的游戏区域。

招式说明页把 `せつめい` 标题与完整正文分别处理，修复“正文已有原译文、实际界面带标题时却无法匹配”的集成遗漏。例如猛撞说明现按两作 RSC 总文本第 6244 条显示“以惊人的气势撞向对手。／自己也会受到少许伤害。”，仅将原换行转换为显示换行。批量原文匹配兼容游戏显示中的全/半角数字、H/P、斜线差异，查找空白也接受复制文本中的 Tab；数字之间的分隔及识别原文保留。标题仍独立保留，不删除任意首行或补齐残句。现有招式说明截图检查见 [记录](reports/move-description/screenshot-checks.json)，重启后生效。

结果区下方提供可选中复制的只读文本框，显示当前译文及保留的日文、数字等识别结果。图片和实时模式均可用鼠标选择文本后按 Ctrl+C 复制，也可在文本框内按 Ctrl+A 全选；实时内容未变化时保留选区，结果失效或停止时同步清除。

排查未翻译内容时，点击“查看匹配说明”。“匹配说明”页用中文列出识别原文、实际查找文本、保留原因和下一步，并提示相同日文在其他窗口、类别或游戏版本中的登记线索；这些线索仅供核对，不改变翻译结果。原始 JSON 诊断保留在“原始数据”页，两个页面均可选中复制。

词库匹配兼容游戏字体中同形的平假名 `へ` 与片假名 `ヘ`，例如 `へラクロス` 可译为原词库的“赫拉克罗斯”，战斗句中的名字同样适用。优先匹配原写法，未命中时才尝试同形写法；沿用类别、版本和译文唯一性检查，识别原文及来源文字保持原样。更新后关闭旧窗口，再双击启动器使用新版。

### F1 问题现场

软件窗口处于前台时，按 **F1**（或点击“保存现场 (F1)”）会在项目 `bugreport/case-时间戳-唯一编号/` 下保存独立 case，完成后界面提示路径，鼠标悬停“现场已保存”可查看路径。实时捕获和打开图片两种模式均可使用。

- `original.png`：未裁剪、未缩放的原始窗口捕获/输入图片；`normalized.png`：标准化游戏图片。
- `recognition.json`：按键时的 OCR 区域、待识别状态、翻译匹配结果和实际显示面板。
- `context.json`：模式、游戏、图像配置、玩家设置、会话/帧编号、映射、稳定与耗时统计、异常和运行环境。
- `matching.txt`、`threads.txt`、`translation-manifest.json`：匹配说明、线程栈和语料版本；通过启动脚本运行时，还保存本进程 stdout/stderr 日志末尾最多各 1 MiB。

保存使用界面当前已发布的帧，不重新捕获或重新识别；图片尚不可用时仍保存诊断信息，并在 context 中标明缺失。统计、线程栈及日志在后台稍后采集。每次保存期间重复按键会被忽略；如果目录中留有 `INCOMPLETE.txt`，表示写入尚未完成或失败。
