每个中文字面引用都有来源文件、固定提交、适用游戏、原记录/词典行、来源及内容 SHA-256 和半开字符范围。运行包只带可复核源证据、规则和原词条，不读截图编号、测试答案或未来帧。

## 当前变量与原有打印

原先因 `variable_printing_unverified` 回退的 101 个去重判断、134 次出现全部已复核，见 [变量审计](variable-binding-audit.json)。**134 次均已恢复原译文/格式，原队列无剩余回退**，不再因“含变量”笼统阻断。该固定队列不随新增规则改变分母。

电脑启动使用原第 2430 条 `[玩家]启动了电脑。`，当前名字为ハルカ便输出 `ハルカ启动了电脑。`。父亲劝告、母亲担心等滚动句在当前名字和称呼齐全时引用完整原段。奖励消息补入原第 6946 条引用，保留原 `$` 格式，只绑定当前玩家和金额。比赛登记使用当前可见等级对应的原词条（如“大师”）；等级尚未显示的 W371 仍原样保留。组织名按当前可见アクア/マグマ绑定原“海洋队”/“熔岩队”，不猜游戏版本。

W145 的日文说对手帮助喜欢的父亲，英语/RSC 将“喜欢”改从父亲一侧表达，并补以“两人的感情很要好呢”。按同一完整帮助/亲情单元保留原本地化，不把这处重心变化误判为未找到翻译。引用两作第 614 条从“他喜欢让[对手]帮他的忙。”到“两人的感情很要好呢。”的连续原范围；当前可见ユウキ绑定 `[对手]`。前面的博士栖息地研究是独立单元，不带入；这项核对不授权忽略其他演员、动作、条件或版本事实差异。

同一占位符标签的实际用途按源调用分别核对：如 `[玩家]` 在电脑、招式和派出意图中并不代表同一个角色。普通经验值保留日文两缓冲与英中三槽的对应证据。新名字、演员、数字、招式、能力、训练家类别、比赛等级和组织名每次从当前输入取值，不登记全局身份或复用前帧值。

原 RSC 两作“跳出来了／出现了”经核对都描述同一野生出现事件。版本未知时明示选择现有红宝石原措辞，同时保留双方原引用；指定版本则输出各自原文。没有另写统一译文，仅当适用版本仍存在多个不同中文输出、无法唯一选择时回退；日中内容差异不触发回退。

原调用、原字面量及来源文件哈希另验证 4 种打印规则，共 14 次出现：当前完整地点原词条＋原“相遇。”；原 `CHAR_LV`＋当前相遇等级＋原逗号（如 `Lv5,`，不新写中文连接词）；原“奖章数: 00”末尾两位按当前计数覆盖；剩余经验值按原调用只显示数字。纯数字/等级格式 8 次单列。未知地点、零/越界/分隔数字、不完整值或未知打印形式不猜测。

## 实际剩余与验收

7 个实际待解决单元：演员残片 2 次；尚未显示比赛等级 1 次；训练家笔记标题未建立原 RSC 对应 4 次。另有 `EXP` 固定标签 4 次按设计保留。海上房子（两次）、猫叫及海边老人首屏均已唯一对应原汉化，直接输出原第 332、1615、197 条的可见范围，保留原措辞和物种名，不因日中差异回退，也不带入后续独立段落。完整原文和来源见逐图审阅。

`baselineGatePassed=true` 表示 1,133 个单元的原引用/格式、当前变量、预期、回退和字段检查一致，不表示全游戏或首版覆盖完成。每个首版输入分别核对两作原来源，共 1,566 个逐作检查；实际截图逐图版本未知。同一模型参与实现和非盲语义核对；冻结预期独立取自已保存的原范围及变量快照，不读取待测 probe 输出，不声称独立人员或盲测。

PC 盒子/存取、商店出售/数量/成交、完整战斗子状态、任意地点及长尾对白等仍待补齐。S6 完成标志与完整首版门槛保持 false。用户暂时跳过 S6 剩余项后，现有规则已接入 [S7 Java 桌面与实时中文](../s7-integration/README.md)，456 张窗口回放与 23 个状态场景通过；真实连续游戏的时序/遮挡、两条设备链路和最终延迟验收仍待完成。

`loadS6Probe(...).visibleProbe.lookupUnit(unit,{type,game})` 是库级入口，与旧静态 `probe.lookup()` 分开。交接包隔离加载无需 ROM、上游缓存或验收答案。

## 复现

```powershell
node tools/build_s6_corpus.mjs
node tools/freeze_visible_window_reference.mjs
node tools/evaluate_visible_windows.mjs --gate
node tools/test_chinese_corpus_acceptance.mjs
node tools/evaluate_s6_corpus.mjs --origin-gate
node tools/audit_s6_progress.mjs
```

仅在来源判断已完成并更新选择后重新冻结，不通过重冻掩盖失败。兼容入口为 `node tools/accept_chinese_corpus.mjs --visible-window-gate`，旧 `--gate` 不恢复已撤回模型答案。

检查包括 [13 项窗口](checks.json)、[14 项变量](variable-binding-checks.json)、[12 项语义单元](semantic-unit-checks.json)及 [8 项原生字段](native-field-checks.json)，覆盖滚动一致、未来单元隔离、当前值替换、原引用/范围篡改拒绝、错误短前缀、原格式边界、版本选择、独立交接和逐字节重现。
