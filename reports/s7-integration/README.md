# S7 原汉化桌面集成

按用户要求暂时跳过 S6 剩余工作，使用现有 S6 原译文包推进 S7。S6 保持未完成，原固定窗口基线和 7 个实际待解决项保持登记。中文仍只来自固定 RSC 原译文，唯一定位后直接使用，不因原译文与日文的含义差异回退。

桌面独立结果区已接入 Java 中文匹配、原模板变量绑定、已审分段和原有打印规则；打开图片和实时窗口捕获都使用同一套解释器。窗口可选择红宝石、蓝宝石或未指定版本，并设置当前玩家日文名。原始 OCR、适用来源、候选、当前变量和回退原因可以在“诊断”中查看。未知或未批准的内容显示日文。

双击项目根目录的 [start-desktop.cmd](../../start-desktop.cmd)。构建后需关闭旧版窗口再启动。软件运行仅需 Java 21，中文资源和捕获组件已随桌面 JAR 打包；Node 只在开发构建时将已验证 S6 资源编译成 Java 可读的数据。

## 当前能力

- 正式中文引用、43 类原模板、41 组显示单元和 4 种原打印规则直接进入桌面链路；没有补译、改写或另造中文格式。
- 同文同译保留全部适用来源；不同版本或不同类型产生不同中文且不能消歧时保留日文。指定版本与当前可靠字段用于选择原文。
- 完整可见的玩家名、人物名和昵称优先查现有原词条；词条不能唯一选择时保留当前原名。战斗中的对方前缀按当前原文保留，昵称查库不推断实际物种。
- 当前可靠玩家名优先，其次为手动设置，再次为本会话确认的玩家名。其他训练家、对手和宝可梦名字不会成为玩家身份。源切换、停止、重新开始清除自动身份，保留手动设置。
- 现有已批准模板仍要求它们所需的当前变量齐全。手动或缓存玩家身份不能补出未定位的残句，也不能填其他演员、招式、地点、数量或比赛等级；现有资源尚无可单独用手动名字补齐的隐藏玩家槽位。
- 中文在原文字区域内重新换行并调整字号；原框、列、数量、数字、选择标记和显示顺序保持所属关系。文字变化、待稳定、消失、暂停和旧异步结果的失效仍由原实时代次机制管理。
- 中文测量终点为实际绘制后的 JavaFX pulse，包含捕获、150ms 稳定等待、OCR、匹配、姓名、变量及绘制；日文保留和未知字形另列。

- [桌面包隔离检查](package-checks.json)：只复制桌面 JAR 到空目录，核对原文、名字、版本冲突、残句、注入和重启；运行不访问 ROM、上游、Node 或验收答案。
- [窗口回放](live/playback-checks.json)：456 张截图及 23 个状态场景通过；[最终桌面包](live-final/playback-checks.json)另核对 18 个代表画面和同一组 23 个状态。回放经过真实 WGC 和 JavaFX，覆盖更新、遮挡、最小化、恢复、校准、窗口切换、停止、残缺字形及内容消失。它验证程序链路，不能替代真实 NDS/NGC 连续游戏。
- [阶段汇总](summary.json)、[输入和实现清单](run-manifest.json)。

最终构建的 34 项桌面检查全部通过。最终包代表集的 [首次尝试](live-final/first-attempt.json)在捕获连接初期漏过两个 750ms 状态，尺寸切换的 1 秒检查也未通过；回放脚本随后明确等待首帧就绪，并等待尺寸切换后可供校准的新帧，按同样的 750ms 内容展示和计时口径重新通过 18 个画面与 23 个状态。全量回放和最终包的实现身份分别保存在各自 `implementation.json`，没有用重建预期隐藏失败。

首次在受限进程中尝试 WGC 时，系统接口报告“指定的服务未安装”；随后使用可访问原生服务的运行方式重新验证，首次失败诊断保留在 [受限运行记录](live/restricted-first-attempt.json)。
