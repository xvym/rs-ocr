## 已暴露并保留的问题

- `ゴースト`：物种名为“鬼斯通”，属性名为“幽灵”。两段英文分别为 HAUNTER／GHOST，必须结合可靠区域与词条类型；静态无上下文查询返回原文回退状态。
- `どく`、`こおり`：属性“毒／冰”与状态“中毒／冰冻”分别保留。`ノーマル` 的“一般／普通”也暂缓统一发布。
- Easy Chat 的 `わざ` 经英文 MOVE 命中“移动”，已按日文订正为“招式”；`おとなしい` 经英文 DOCILE 命中性格“坦率”，已按日文改为“温顺”。这类修订保留原文与实际模型方法。
- Easy Chat 的 `ノーマル` 对应英文 EVOLUTION／汉化“进化”，体现日英本地化差异；不能仅凭英文桥沿用中文。
- RS 内部物种索引不是全国图鉴编号，例如 252 为占位，木守宫位于内部索引 277；建库按实际源记录处理。
- 6,887 条记录包含日文排版／控制或括号项，已进入语义与打印审查清单。`STR_VAR_1` 等缓冲及战斗缓冲的类型必须结合调用点，当前规则不批准动态绑定。Easy Chat、电视节目、对战塔的组合对白仍有缺口，少数词语核对不代表组合机制已支持。

3. 核对日版打印、变量用途和长度、重复槽位、战斗前缀与完整可见值；按实际语义建立窗口与中文单元，逐条补译缺口。当前静态包只能用于 S7 起步，不能代替正式动态语料。
4. 扩大日中语义核对，处理未决同文多译，保存订正与统一决定，按已冻结中文答案回归库级门槛；S7／S8 再补全最终 A6。
