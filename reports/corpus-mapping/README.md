## 已暴露并保留的问题

- `ゴースト`：物种名为“鬼斯通”，属性名为“幽灵”。两段英文分别为 HAUNTER／GHOST，必须结合可靠区域与词条类型；静态无上下文查询返回原文回退状态。
- `どく`、`こおり`：属性“毒／冰”与状态“中毒／冰冻”分别保留。`ノーマル` 的“一般／普通”也暂缓统一发布。
- Easy Chat 的 `わざ` 经英文 MOVE 命中“移动”，已按日文订正为“招式”；`おとなしい` 经英文 DOCILE 命中性格“坦率”，已按日文改为“温顺”。这类修订保留原文与实际模型方法。
- Easy Chat 的 `ノーマル` 对应英文 EVOLUTION／汉化“进化”，体现日英本地化差异；不能仅凭英文桥沿用中文。
- RS 内部物种索引不是全国图鉴编号，例如 252 为占位，木守宫位于内部索引 277；建库按实际源记录处理。
- 6,887 条记录包含日文排版／控制或括号项，已进入语义与打印审查清单。`STR_VAR_1` 等缓冲及战斗缓冲的类型必须结合调用点，当前规则不批准动态绑定。Easy Chat、电视节目、对战塔的组合对白仍有缺口，少数词语核对不代表组合机制已支持。

## 后续完成顺序

1. 按首版支持目录建立“页面／区域—源记录”关系，为两个摘要页、背包、商店、队伍、PC、战斗模板和剧情对白分别建立应翻译分母；现有源码分组不能替代实际页面覆盖。
2. 审查英文未对应／编码缺口和仅同文候选，补全改名符号、成员、内部子串及两作差异；对照日文处理实质本地化差异。
3. 核对日版打印、变量用途和长度、重复槽位、战斗前缀与完整可见值；按实际语义建立窗口与中文单元，逐条补译缺口。当前静态包只能用于 S7 起步，不能代替正式动态语料。
4. 扩大日中语义核对，处理未决同文多译，保存订正与统一决定，再进行独立中文标注及最终 A6 验收。

## 中文验收提案（尚未成为 Spec A6 门槛）

建议先以现有 579 个目标区域建立中文独立答案：每项登记完整原始日文、当前可见语义单元、所需变量、应显示中文、合法原文保留、适用版本和来源。答案应在查看系统输出前独立完成并冻结；可由离线模型辅助，须标明方法与另一次核对，不能直接把候选库导出充当独立答案。

分母分别为：应翻译语义单元、合法原文保留单元、当前应显示的数字／符号。昵称未收录时保留其完整日文属于合法行为；整句因未决译文而回退仍计为未覆盖。数值必须逐项保持当前画面值。目标文字被挡的 11 个区域继续单列排除及无误输出检查。

建议固定集门槛为应翻译单元覆盖 100%、已发布译文语义正确 100%、数字／合法原文保留／冲突回退符合预期 100%，不允许提前显示下一独立语义单元或沿用过期内容。还须按首版类别和两作补充模板、长短名字、重复槽位、同文异义、版本区别、滚动／翻页与缺译的独立场景，逐类报告，避免固定截图中缺少某类就视为通过。当前逐图游戏归属尚有缺项，不能编造分作验收统计。
