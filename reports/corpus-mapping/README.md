# 原 RSC 译文映射库

当前只保留原汉化措辞，禁止模型补译或修改中文。原模型资源、中文答案和 770/770、25/770 门槛已[撤回归档](../../archive/model-translations/README.md)。当前正式包见 [S6 报告](../s6-corpus/README.md)，来源检查见 [当前报告](../s6-acceptance/README.md)；S6 及中文语义验收尚未完成。

新增 [正式来源对应索引](../rsc-correspondence-index/README.md)与原地址候选分开保存：197 个确认日文 qid 对应 448 条逐作/逐来源关联，另有 772 条图鉴父记录关联，合计 1,220 条。原地址表和以下基线数量保留；`correspondences.json` 及 `correspondence-gaps.csv` 表示计入确认对应后的索引状态，所有新关联都不直接批准译文输出。

固定输入仍为 13,479 条日英记录、两作各 9,805 条汉化及四份原 RSC 名称词典，生成 21,192 条原中文候选。旧静态清单删除 36 条补译，31 条修改恢复为 `originalChinese`，保留 404 条来源选择。构建器只接受 `retain`；来源、游戏、qid、原候选集合及原译文必须一致。
