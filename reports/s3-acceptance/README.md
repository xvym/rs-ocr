## 重现

先按 [开发说明](../ocr-development/README.md)构建同一版本，然后执行：

```powershell
.\run-offline.ps1 -Directory gba_testcase -Profile gba-5x -Out .tools/s3-gba-raw.json -JavaHome '<JDK 21 路径>'
.\run-offline.ps1 -Directory ngc_testcase -Profile ngc-capture -Out .tools/s3-ngc-raw.json -JavaHome '<JDK 21 路径>'
python tools/accept_s3.py --results .tools/s3-gba-raw.json .tools/s3-ngc-raw.json
python tools/test_s3.py
```

`accept_s3.py` 退出码 0 表示本次 S3 通过，1 表示实际指标未满足。遗漏原图、重复帧、错误图片哈希、旧引擎输出或冻结证据改变会明确拒绝。发布前如更换构建，应核对资源及实现身份后重新冻结对应版本；不能修改哈希绕过未审阅的内容变化。

`freeze_s3.py` 仅在复核完成后用于重建快照，不读取预测；它校验已经审阅的输入身份、29 张拼图及复用实例，不自动产生 AI 复核结论。
