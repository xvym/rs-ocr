## 方法与边界

先重建原汉化地址的英文底稿，检索日文／英文完整同文、忽略排版的对应、已有词条及全部项目分支，再用英文全文排序召回其他候选；对有完整候选的 269 条及 11 条重点语义查询共 280 条进行模型语义核对。部分英文缺失记录使用根据日文含义提出的英文检索词；检索词不作为中文译文。

实际方法为全文召回加非盲模型语义比较，**没有使用嵌入模型，也没有对其余未命中项完成穷尽的逐句语义判定**。同一模型参与实现和复核，不宣称独立人员验收。相似度不等于语义一致；未命中不证明不存在。此报告不构成 S6 完成、中文语义验收通过或 S7 发布许可。

本报告及其 1,772 条分母是原地址候选索引的检索快照。随后 197 个已确认日文 qid 的 448 条逐作/逐来源对应已写入 [正式对应索引](../rsc-correspondence-index/README.md)，来源复核与运行发布继续分开；本报告是旧检索快照，当前唯一原 RSC 来源不受语义等价或译文质量否决。27 条部分对应和未确认项没有自动纳入确认选择；其后 [原汉化反查](../rsc-reverse-mapping/README.md)另经来源核对确认 35 条记录和 18 条精确日中片段，片段仍不计作整条覆盖。本报告的历史召回分母不随入库改写。当前整体对应缺口另见 `outputs/corpus-mapping/correspondence-gaps.csv`。

## 复现与数据

```powershell
node tools/prepare_rsc_semantic_audit.mjs
node tools/audit_rsc_semantic_correspondence.mjs
node tools/review_rsc_semantic_audit.mjs
node tools/test_rsc_semantic_audit.mjs
```

首次准备需联网读取固定提交；之后离线运行。解析与原文引用检查不读取旧模型译文档案。

- [汇总](summary.json)、[逐 qid 状态](semantic-worklist.csv)、[语义复核及原文引用](semantic-review.json)。
- `retrieval.json` 保存全部缺口及候选 ID，`retrieval-documents.json` 保存去重原记录；`worklist.csv` 保存逐作召回状态。
- `source-manifest.json` 记录完整文本清单；`run-manifest.json` 与 `semantic-review-manifest.json` 分别绑定召回与语义复核的输入、实现和制品。
- [10 项检查](checks.json)验证分母、逐字原文引用、逐作来源、假匹配回退、盲文保留、哈希及正式包未改变，不代替独立语义准确率。
