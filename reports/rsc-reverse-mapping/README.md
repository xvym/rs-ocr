本轮 [115 条来源复核](source-review.json)和 [选择快照](../../corpus/rsc-reverse-reviews.json)保留全部原分母、当前判断及原因。中文引用逐字重取原汉化；没有补译、改写或合并原记录。

新增对应主要来自字符串内部偏移、名字结构字段和多对一记录：比赛昵称严格对应昵称字段，不能套到训练家姓名；公斤单位只对应日文 `ｋｇ`，不包含未知数值，也不将英文磅数换算；“一点反应都没有。”只引用原无反应句，排除前面的不同语气词。忘记／学会与拒学招式是同一日文记录中的互斥分支，分别绑定两个原汉化条目，保存不相交日文范围，不拼接发布。

## 图鉴分页是主要漏关联原因

原地址候选索引中，每作有 387 条图鉴第二页没有日文候选。源数据把英文介绍分为 `DexDescription_*_1` 和 `DexDescription_*_2`，原汉化也按两条保存；日文则把整段介绍存入 `_1`，同名 `_2` 的日文栏为 `[NULL]`。原地址建库流程跳过空日文与 `[NULL]`，因此没有挂回这些中文第二页；新增对应索引保留其父记录关系，仍不生成独立日文第二页。

386 条真实宝可梦介绍都找到了同版本、同物种的非空日文 `_1`；另 1 条 `Dummy_2` 是占位介绍，不能因为标签相似而当作已匹配。

例如红宝石原汉化：

- `DexDescription_Bulbasaur_1`：`会看到它在太阳底下\n睡午觉的样子。`
- `DexDescription_Bulbasaur_2`：`沐浴了充足的阳光后，\n它背上的种子就会茁壮成长。`

它们的日文整段已存在于 `rs.common.pokedex_entries^R.DexDescription_Bulbasaur_1`：

```text
ひなたで　ひるねを　する　すがたを　みかける。
たいようの　ひかりを　いっぱい　あびることで
せなかの　タネが　おおきく　そだつのだ。
```

因此这里的 `[NULL]` 表示没有独立的第二条日文记录，不代表第二页中文所表达的内容在日文中不存在。需要支持“多条原汉化记录对应一条日文记录”，继续核对具体语义范围和实际显示窗口；不能按行数或页数机械均分，也不能直接拼接中文后宣称可发布。
